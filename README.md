## Featured Projects

### 🔐 Active Directory & GPO Security Lab
**Technologies:** Windows Server, Active Directory, DNS, Group Policy, Windows 10 Pro

- Built a full Active Directory environment with a Domain Controller and client
- Designed enterprise-style Organizational Units (geographic structure)
- Implemented password, account lockout, drive mapping, wallpaper, and removable storage GPOs
- Troubleshot real-world issues including DNS failures, domain join errors, NTFS permissions, and GPO reporting
- Validated policies using `gpresult`, `net accounts`, and client-side testing

📁 `/projects/Microsoft Active Directory/`
